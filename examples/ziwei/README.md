# 紫微斗數 Zi Wei Dou Shu

用紫微斗數框架分析上市公司（以騰訊為例），透過流年四化量化宮位能量波動，測試同股價嘅相關性。

## 框架邏輯

```
CEO性格 → 鎖定關鍵宮位 → 流年四化分數波動 → 業務表現 → 股價
```

## 檔案說明

| 檔案 | 用途 |
|------|------|
| `three_chain_test.py` | 三鏈假說測試（福德→保守→股價） |
| `fude_10yr.py` | 福德宮 10 年分數走勢圖 |
| `fude_detail.py` | 福德宮流年四化詳細拆解 |
| `fude_vs_conservatism.py` | 福德宮分數 vs 保守程度指數 |
| `tencent_chart.py` | 騰訊 12 宮年度分數 + 股價圖表 |

## 核心發現

- 12 宮中僅**福德宮**同股價有顯著相關（r = -0.520, p = 0.019）
- 夫妻宮、子女宮同股價相關性不顯著
- 「福德高分→保守操作→股價跌」三鏈中介假說不成立
- 20 年樣本量有限，結果可能係統計噪音
