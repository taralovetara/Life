# Life — 中國術數量化系統

將中國傳統術數（紫微斗數、奇門遁甲）量化成數學模型，用 Python 實現。

## 項目結構

```
├── ziwei/                  # 紫微斗數核心引擎
│   ├── calculator.py       #   排盤引擎
│   ├── scorer.py           #   量化評分系統
│   ├── timeline.py         #   大限/流年時間軸
│   ├── constants.py        #   全部常量與查找表
│   ├── cli.py              #   命令行界面
│   └── stock_backtest.py   #   股價回測模組
├── qimen/                  # 奇門遁甲引擎
│   └── engine.py           #   完整起局+評分+決策
├── examples/
│   ├── ziwei/              # 紫微斗數應用範例
│   │   ├── three_chain_test.py    # 三鏈假說測試
│   │   ├── fude_10yr.py           # 福德宮走勢圖
│   │   ├── fude_detail.py         # 福德宮四化拆解
│   │   ├── fude_vs_conservatism.py # 福德宮 vs 保守度
│   │   └── tencent_chart.py       # 12宮+股價圖表
│   └── qimen/              # 奇門遁甲應用範例
│       └── (待擴充)
├── tencent_backtest.png    # 紫微回測圖
└── requirements.txt
```

## 兩套系統嘅分工

| 維度 | 紫微斗數 `ziwei/` | 奇門遁甲 `qimen/` |
|------|-------------------|-------------------|
| **用途** | 年度大方向預測 | 即時時機揀選 |
| **粒度** | 年 | 時辰（2小時）|
| **基底** | 本命盤（出世固定）| 地盤（~5日一變）|
| **變化** | 流年四化 | 天/人/神盤飛布 |
| **適合** | 「今年騰訊點樣？」| 「今日幾點入？」|
| **複雜度** | 解讀複雜 | 計算複雜 |

## 紫微斗數量化框架

### 宮位評分公式

```
宮位分數 = Σ(主星亮度 × 權重) + Σ(吉星) - Σ(煞星) + Σ(四化)
```

### 核心發現（騰訊 2004-2025）

- 12 宮中僅**福德宮**同股價顯著相關（r = -0.520, p = 0.019）
- 三鏈中介假說（福德→保守→股價）不成立

## 奇門遁甲量化框架

### 宮位評分公式

```
宮位總分 = 星分 + 門分 + 神分 + 干支生剋 + 格局加減分
```

### 決策閾值

- ≥ +5.0 強烈看多 | ≥ +2.0 偏多 | ≥ -2.0 觀望 | ≥ -5.0 偏空 | < -5.0 強烈看空
