奇門遁甲 完整計算流程

Qi Men Dun Jia — From Datetime to Decision

1. 時間輸入
唯一輸入：datetime → 例如 2026-08-03 01:44
解析
2. 日曆計算
JDN 公式 → 日干支（戊辰）  |   hour → 地支 → 時辰干支（癸丑）
時辰天干 = 癸  |  時辰地支 = 丑  |  旬首 = 甲辰 → 值符星 = 天心
確定局數
3. 節氣 & 局數
日期 → 當前節氣（大暑） →  base 局數（7） →  元（下元，第 10-15 日）
陰遁5局 — 決定地盤飛布方向（逆飛 9→1）
四層輪盤
4. 四層輪盤飛布
地盤 Earth Plate
六儀三奇（戊己庚辛壬癸丁丙乙）從局數宮開始排入九宮
驅動：節氣 + 元 + 陰陽遁
每 ~5 日一轉
天盤 Heaven Plate
值符星 + 九星 + 天干，飛到時辰天干在地盤嘅位置
驅動：時辰天干
每 2 小時一轉
人盤 Human Plate
值使門 + 八門，飛到時辰地支對應嘅宮位
驅動：時辰地支
每 2 小時一轉
神盤 Spirit Plate
值符神 + 八神，從值符星所在宮位開始排
驅動：值符星位置
每 2 小時一轉
疊加
5. 交匯 → 落入九宮格

以 2026-08-03 01:44 丑時為例
格內運算
6. 每格內部運算（三項 variable 計算）
星 / 門 / 神分數
每個元素帶基礎分數
例：天輔 +2.5
開門 +3.0
太陰 +1.5
五行生剋
天干五行 vs 地干五行
例：己(土) vs 丙(火)
火生土 → +0.8
格局偵測
天干+地干+門+神
嘅特定組合觸發
例：乙+辛 → 青龍逃走 -3
加總
7. 評分
宮位總分 = 星分 + 門分 + 神分 + 五行生剋係數 + 格局加減分
以兌7宮為例：(+2.5) + (+3.0) + (+1.5) + (+0.8) + (0.0) = +7.8
用神取用
8. 決策
根據問題揀用神宮位 → 睇分數 → 落閾值
≥ +5.0
強烈看多，加倉
≥ +2.0
偏多，可買入
≥ -2.0
觀望，唔操作
≥ -5.0
偏空，減倉
< -5.0
強烈看空，清倉
例：Long Gold → 用神=開門 → 開門喺兌7宮 → +7.8 → 強烈看多，加倉
