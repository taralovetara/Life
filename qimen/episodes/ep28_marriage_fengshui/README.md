# EP28: 婚姻感情風水 — 夫妻宮 + 臥室五種常見問題

**頻道**: 天心堂 坤正師傅
**主題**: 夫妻宮作為婚姻第一用神 + 臥室風水對婚姻感情的影響
**量化日期**: 2026-08-12

## 本集概述

本集揭示一個重要顛覆性觀點：**夫妻宮才是婚姻第一用神，影響力遠比乙庚關係大**。前半講夫妻宮概念和解釋「乙庚相剋但婚姻仍好」的現象，後半講臥室五種常見風水問題及其對婚姻的影響。

## 核心知識點

### 1. 夫妻宮 = 婚姻第一用神（重大觀點更新）

| 優先級 | 用神 | 說明 |
|--------|------|------|
| **第一** | **夫妻宮** | 影響力最大 |
| 第二 | 乙庚關係 | 長期趨勢（EP10/EP26） |
| 第三 | 日時關係 | 短期現狀（EP26） |

- **夫妻宮定義**：**六合的落宮**
- **輔助參考**：休門的落宮
- 夫妻宮格局好 → 即使乙庚相剋，仍可一起生活幾十年
- 夫妻宮格局差 → 即使乙庚好，仍可能離婚
- 夫妻宮起「通關」作用 → 亦可化解乙庚相剋

> **這個觀點更新了 EP02/EP10 的婚姻預測框架**
> EP02-10 以乙庚為主，EP28 明確指出夫妻宮 > 乙庚

### 2. 奇門遁甲風水應用

- 奇門遁甲**唔止可以做預測**，仲可以運用在**勘察風水**
- 用羅盤確定夫妻宮在住宅裡的實際方位
- 可以發現房子哪個位置出了問題

### 3. 夫妻宮落在衛生間

- 衛生間 = 最污穢、最潮濕、病菌最多的地方
- 夫妻宮在此位置 → 婚姻感情很難維持健康
- 案例：女士搬新居後夫妻關係逐漸惡化，丈夫出軌

**解決方法**（由易到難）：
1. 奇門遁甲調理（無須大興土木）
2. 重新裝修，改變衛生間位置
3. 換房子搬家

### 4. 臥室五種常見問題

#### 問題一：雜物太多（病土）
- 雜物/垃圾五行屬**土**，且係「有病的土」
- 病土堆積 → 身心受影響 → 夫妻關係難倖免
- **化解**：做有門儲物櫃，將雜物收納，唔暴露出來

#### 問題二：光線太亮
- 臥室 = 休息睡覺的地方
- 光線太亮 → 影響睡眠 → 情緒受影響 → 易發脾氣 → 夫妻磨擦
- **化解**：選擇光線柔和的燈，營造溫馨浪漫氣氛

#### 問題三：鏡子正對睡床
- 鏡子 = 陰性很強的物品（可反射煞氣）
- 鏡子對床 → 煞氣反射到床上的人 → 精神緊張、焦慮、惡夢
- **化解**：用無固定安裝的梳妝鏡，用完收起

#### 問題四：臥室面積太大
- 面積太大或窗太多 → 氣場不穩定
- 比喻：一葉輕舟飄蕩在波濤洶湧的大海上
- **化解**：裝修時將臥室做到大小適中，保持氣場穩定

#### 問題五：三角形/箭頭型圖案太多
- 三角形/箭頭五行屬**火**
- 床單、被套、枕頭套有這些圖案 → 臥室火氣十足
- 火係最不穩定元素之一 → 燥火大 → 易爆發衝突
- **化解**：避免在床上用品使用三角形/箭頭圖案

### 5. 適用範圍
- 已婚夫婦
- **同居男女朋友**（同樣適用）
