# EP22: 轉盤四盤完整排布 + 驛馬計算 + 空亡整合

## 資料來源
天心堂坤正師傅 第二十二集

## 本集新知識點

### 1. 轉盤引擎核心：後天八卦順時針8宮序
- 轉盤唔係按洛書數字飛跳，而係按後天八卦方位旋轉
- 陽遁順時針：`[1, 8, 3, 4, 9, 2, 7, 6]`（坎→艮→震→巽→離→坤→兌→乾）
- 陰遁逆時針：`[6, 7, 2, 9, 4, 3, 8, 1]`
- 中五宮唔參與8宮旋轉，寄坤二

### 2. 天盤排布（九星 + 天干）
- 值符確定：旬首六儀在地盤嘅宮位 → 該宮原始天星 = 大值符
- 位移計算：時干在地盤宮位 vs 值符本宮 → 後天八卦序中嘅偏移量
- 九星統一旋轉同一偏移量（天禽寄天芮）
- 天干同步旋轉，中五天干跟隨寄宮

### 3. 人盤排布（八門）
- 值使門確定：值符星 → 對應門（天蓬↔休門等9對固定映射）
- 時宮計算：用洛書9宮飛布序（含中五），從旬首六儀地盤宮位飛步數
- 八門反向排列：洛書8宮序 + 反向

### 4. 神盤排布（八神）
- 小值符（值符神）跟隨大值符（值符星）落宮
- 其餘七神按後天八卦順/逆時針依次排布
- 陽遁順排、陰遁逆排

### 5. 驛馬計算（G32 解決）
- 口訣：申子辰在寅，寅午戌在申，巳酉丑在亥，亥卯未在巳
- 驛馬 = 移動、變動、遠行
- 根據時支查表即得驛馬地支 → 轉宮位

### 6. 空亡整合（G27 解決）
- 空亡地支 = 該時辰所在旬中唔出現嘅兩個地支
- 6旬 × 2空亡 = 完整映射表
- 空亡宮位喺盤面標註，影響評分

### 7. 九星本宮映射
- 宮位→原始天星：`JIUXING_HOME` {1:天蓬, 2:天芮, 3:天沖, 4:天輔, 5:天禽, 6:天心, 7:天柱, 8:天任, 9:天英}
- 反向查找：星名→本宮 `JIUXING_HOME_R`
