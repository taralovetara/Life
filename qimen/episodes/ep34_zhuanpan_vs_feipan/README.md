# EP34: 轉盤奇門 vs 飛盤奇門

**頻道**: 天心堂 坤正師傅
**主題**: 兩大流派全面對比
**量化日期**: 2026-08-13

## 本集概述
本集系統性介紹奇門遁甲兩大流派嘅差異：符號（八神vs九神、八門vs九門）、排列順序、起局方法（轉vs飛）、中五宮處理、伏吟反吟特性、預測方法兼容性。結論：兩者預測能力同一水平，關鍵在師傅功力。

## 核心知識點

### 1. 歷史
- 轉盤：東晉時期
- 飛盤：清朝
- 都是正統流派，古籍有記載

### 2. 符號差異
- 轉盤八神：值符/螣蛇/太陰/六合/白虎/玄武/九地/九天
- 飛盤九神：值符/螣蛇/太陰/六合/勾陳/太常/朱雀/九地/九天
- 轉盤八門：休生傷杜景死驚開
- 飛盤九門：休死傷杜中開驚生景（多中門）

### 3. 起局差異
- 轉盤：轉（順/逆時針旋轉）
- 飛盤：飛（後天八卦飛跳）
- 轉盤中五宮空出需寄宮，飛盤九門九神全入

### 4. 伏吟反吟
- 轉盤：一宮伏吟=全盤伏吟（固定對衝）
- 飛盤：可以局部伏吟（無固定相對位置）

### 5. 兼容性
- 兩套完全獨立嘅技術體系，唔可以混用

### 6. engine_v2.py 定位
- 確認為轉盤奇門引擎，無需改動
