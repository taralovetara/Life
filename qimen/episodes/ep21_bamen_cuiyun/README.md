# EP21: 八門催運法 + 兩周預測

## 核心內容

### 八門催運法
- 適用：**多對手**博弈（麻將、投標、鬥地主等）
- 不適用：單對手（用孤虛法）
- 核心：開門、休門、生門三吉門落宮評分，選最佳方位

### 評分標準（0-100分）
| 加分 | 扣分 |
|------|------|
| 三奇（乙丙丁）| 凶格 |
| 吉星（天心天任天輔）| 門迫 |
| 吉神（值符太陰六合九地九天）| 凶神（騰蛇玄武白虎）|
| 吉格 | 六儀擊刑 |
| 得地 | 入墓 |

### 孤虛法釐清
- 孤虛法只適用於**一個對手**
- 多對手場景無法安排所有人到虛位

## 量化函數
- `bamen_cuiyun(r)` — 八門催運法
- `print_bamen_cuiyun(bc)` — 格式化輸出

## 案例
- 麻將牌局：休門巽四宮90分 > 開門震三/生門離九各70分 → 坐東南方
