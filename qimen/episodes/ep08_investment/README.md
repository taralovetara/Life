## 本集新知識

1. **八門完整含義**：每個門的含義、適用/不適用場景系統化
2. **投資經營五用神**：開門=開業、日干=求測人、時干=投資事件、生門=利潤、戊=資金
3. **生門多面性**：利潤 + 生意本身；無形投資直接看生門不看開門
4. **資金雙層分析**：天盤戊=表面資金、地盤戊=資金真相
5. **地盤干+月干交叉驗證**：追蹤地盤己落宮識破拍檔資金造假
6. **新天干組合**：壬+丙=變動、丙+己=籌劃、丁+壬=產品種類多
7. **投資分析三組核心關係**量化

## 關鍵發現

### 投資分析框架
| 關係 | 含義 | 判斷邏輯 |
|------|------|----------|
| 開門宮 vs 日干宮 | 投資對求測人的影響 | 開門剋日干=不好 |
| 時干宮 vs 日干宮 | 事件對求測人的影響 | 時干剋日干=有害無益 |
| 生門宮 vs 戊宮 | 利潤 vs 資金 | 生門剋戊=肯定虧本 |

### 無形投資用神差異
- 有形投資（開實體店）→ 開門 + 生門 + 日干 + 時干 + 戊
- **無形投資（金融產品/MPF）→ 不看開門，直接看生門**
