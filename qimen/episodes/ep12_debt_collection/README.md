# EP12: 追討欠債預測 + 伏吟局與反吟局

**頻道**: 天心堂 坤正師傅
**主題**: 追債成敗預測方法 + 伏吟/反吟局基礎知識
**量化日期**: 2026-08-07

## 本集新知識

1. **追債用神系統**：值符=債主、天乙=欠債人、傷門=追債人
2. **天乙定義**：值符落宮原來的地盤天星（動態計算，非固定符號）
3. **追債五步框架**：分析三用神宮符號 + 五行生剋比和 + 日干時干輔助
4. **伏吟局四種**：星伏吟、門伏吟、天干伏吟、全伏吟
5. **伏吟規則**：利主不利客、被動慢、拖拖拉拉；例外：收斂財貨（買入/追債）最有利
6. **伏吟最凶**：天蓬+天蓬、死門+死門、庚+庚 → 破財死傷
7. **反吟局四種**：星反吟、門反吟、天干反吟、全反吟
8. **反吟規則**：利客不利主、主動快急、虎頭蛇尾；例外：賣貨求財最有利
9. **衝格擴展**：逢衝必動 + 逢衝必散（辛+戊=錢財逢衝必散）
10. **合格雙面性**：穩定=行動力不佳（乙+庚=事情難以開展）

## 關鍵發現

### 伏吟/反吟與主客關係的理論聯繫
- EP11 確立：天盤=客、地盤=主
- 伏吟（天干=地干）→ 客不動 → 利主
- 反吟（符號跑到對宮）→ 客主動 → 利客
- 不再只是經驗規則，有理論基礎

### 合格含義演變
| 集數 | 含義 |
|------|------|
| EP07 | 穩定（丁+戊、壬+丁）|
| EP10 | 穩當實在（癸+戊、戊+乙）|
| EP12 | 行動力不佳、難以開展（乙+庚）|

核心：合格=穩定不動，靜態場景=好、動態場景=差

### 動態用神：天乙
- 天乙不是固定符號，每個盤局的天乙都不同
- 查找方法：值符落宮 → 原地盤天星 = 天乙
- 例：值符落震三宮 → 原天星=天衝星 → 天乙=天衝星

### 伏吟/反吟對照
| 維度 | 伏吟 | 反吟 |
|------|------|------|
| 符號位置 | 留在本宮不動 | 落在對宮相衝 |
| 主客 | 利主不利客 | 利客不利主 |
| 時間 | 比較長 | 比較短 |
| 策略 | 被動、慢 | 主動、快急 |
| 例外 | 買入/追債有利 | 賣貨求財有利 |
