# EP16: 起局時間原則 + 常用吉格

**頻道**: 天心堂 坤正師傅
**主題**: 奇門遁甲起局時間原則 + 常用吉格介紹
**量化日期**: 2026-08-07

## 本集新知識

1. **無事不占**：必須有真實渴求想知道的事才能起局
2. **不動不占**：必須在起念或外應出現時起局
3. **起念時間 > 事情發生時間**：用突然想問測的時間起局
4. **不用出生盤**：問特定事情用起念時間，不用出生盤（終身問測除外）
5. **格局定義**：八神/九星/八門/十天干落在九宮的組合
6. **玉女守門**：值使門+地盤丁同宮（丁必須地盤）
7. **三奇貴人升殿**：乙落震3 / 丙落離9 / 丁落兌7（任一）
8. **奇遊祿位**：三奇落各自臨官位（乙震3/丙巽4/丁離9），與EP15十二長生銜接
9. **天輔吉時**：五合日+甲X時，必為伏吟局
10. **三詐五假**：真/重/休詐+天/地/人/神/鬼假（具體組合待補）
