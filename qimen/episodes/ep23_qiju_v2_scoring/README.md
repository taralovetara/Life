# EP23: V2 增強評分系統 + 統一起局入口

## 資料來源
天心堂坤正師傅 第二十三集

## 本集新知識點

### 1. 統一起局入口 `qiju_v2()`
- 整合 Part 1-3 所有量化規則，一個函數完成完整起局
- 輸入 `datetime` + 可選 `scene`，返回包含四盤+評分+格局+預測嘅完整 dict
- 自動偵測伏吟/反吟、五不遇時、天輔吉時
- 自動計算空亡、驛馬
- 可觸發 11 個場景預測函數

### 2. V2 增強評分公式
`palace_score_v2()` = V1基礎分 + 格局分 + 六儀擊刑 + 門迫 + 入墓 + 得地 + 十二長生旺

| 項目 | 說明 | 分數範圍 |
|------|------|----------|
| 星分 | 九星吉凶 | -2.0 ~ +3.0 |
| 門分 | 八門吉凶 | -3.0 ~ +3.0 |
| 神分 | 八神吉凶 | -2.5 ~ +3.0 |
| 干支生剋 | 天盤干 vs 地盤干五行 | -1.5 ~ +0.8 |
| 格局總分 | 統一偵測所有格局 | 動態 |
| 六儀擊刑 | 6個固定組合 | -2.0 |
| 門迫 | 12+組 | -2.0 |
| 天干入墓 | 10干對應 | -2.5 |
| 八門入墓 | 8門對應 | -2.0 |
| 得地 | 門回本宮/宮生門 | +1.0 |
| 長生旺 | 用神處旺態 | +0.5 |

### 3. V2 決策閾值調整
- ≥+5.0 強烈看多 | ≥+2.0 偏多 | ≥-2.0 觀望 | ≥-5.0 偏空 | <-5.0 強烈看空
- 相比 V1 放寬，因為格局分令分數範圍更大

### 4. 增強盤面輸出 `print_chart_v2()`
- 顯示局類型（伏吟/反吟）
- 顯示五不遇時、天輔吉時
- 顯示空亡、驛馬
- 每宮列出觸發嘅格局標籤
- 評分排名含入墓/擊刑/門迫/得地/旺 標記

### 5. 多場景一鍵預測
- `qiju_v2(dt, scene='lawsuit_civil')` → 自動跑民事官司
- `qiju_v2(dt, scene='health')` → 自動跑疾病預測
- `qiju_v2(dt, scene='exam')` → 自動跑考試預測
- 支援全部 11 個場景
