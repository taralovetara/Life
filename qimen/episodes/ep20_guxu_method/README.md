# EP20: 孤虛法 + 每周最佳時間方位

## 核心內容

### 孤虛秘法
- 孤 = 空亡位（盤局空亡地支）
- 虛 = 空亡位對衝方位
- 適用：**單一對手**的博弈/談判
- 不適用：多對手（用八門催運法）、無對手（用每日最佳時間方位）

### 關鍵規則
- 時支屬陽 → 選陽性空亡地支為孤位
- 時支屬陰 → 選陰性空亡地支為孤位
- 陽支：子寅辰午申戌
- 陰支：丑卯巳未酉亥
- 自己背對孤位、面向虛位

### 每周最佳時間方位
- 逐日逐時辰起局評分
- 找最佳時辰+最佳方位
- 大事勿用日識別

## 量化函數
- `calc_guxu(sgz)` — 孤虛法計算
- `get_xunkong(jz)` — 空亡地支
- `best_time_direction(dt)` — 每日最佳時辰
- `weekly_forecast(start_date)` — 每周預測
