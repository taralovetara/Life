# EP32: 取用神 — 預測核心嘅九種定位方法

**頻道**: 天心堂 坤正師傅
**主題**: 九種取用神方法 + 四柱天干父母用神詳細案例
**量化日期**: 2026-08-13

## 本集概述

本集系統性介紹奇門遁甲預測中最關鍵嘅步驟：**取用神**。用神就係預測事物嘅代表符號，係預測嘅核心。取對用神對準確度有決定性影響。全集講解九種常用取用神方法，每种都配有具體例子，最後用一個父母問測案例示範四柱天干方法嘅三種變化。

## 核心知識點

### 1. 用神嘅定義
- **用神** = 預測事物嘅代表符號 = 預測核心
- 奇門遁甲有超過 60 個符號，每個都可以做用神
- 優點：描述精細真確
- 缺點：花多眼亂，容易取錯
- 取對用神 = 準確預測嘅第一前提

### 2. 九種取用神方法總覽

| # | 方法 | 核心邏輯 | 適用場景 |
|---|------|---------|----------|
| 1 | 日干時干 | 日干=求測人，時干=問測之事 | 通用，最常用 |
| 2 | 四柱天干 | 年=父母/領導，月=平輩，日=自己，時=晚輩 | 家庭/職場關係 |
| 3 | 主客關係 | 先動為客(天盤)，後動為主(地盤) | 連續問測多人 |
| 4 | 年命 | 出生年份天干=當事人 | 知道年份時優先用 |
| 5 | 九宮八卦 | 宮位對應人物類型 | 只知大概年齡時 |
| 6 | 方位 | 求測人/事件方位=用神宮 | 已知方位時 |
| 7 | 六親關係 | 以年命為基礎推算親屬用神 | 複雜家庭問測 |
| 8 | 專門用神 | 事物特定代表符號 | 婚姻/官司等專題 |
| 9 | 報數編號 | 求測人隨機編號→對應宮位 | 多選項比較 |

### 3. 方法一：日干時干（最常用）
- **日干** = 求測人自己
- **時干** = 求測之事或人士
- 既有隨機性，也有針對性
- 係奇門遁甲**無須知道出生八字**嘅原因之一
- 前面 31 集大量使用呢種方法

### 4. 方法二：四柱天干（本集重點）

#### 基本對應
| 四柱 | 代表人物 |
|------|---------|
| 年干 | 父母、長輩、領導 |
| 月干 | 兄弟姊妹、同事、朋友、平輩 |
| 日干 | 求測人自己 |
| 時干 | 子女、下屬、晚輩 |

#### 五組合干
甲己合、乙庚合、丙辛合、丁壬合、戊癸合

#### 問測父母嘅三種情形（核心案例）

**案例背景**：庚子年、己卯月、甲戌日、壬申時，一位女士問測父母

**情形一**：籠統問父母雙親
- 年干庚 = 用神，分析天盤庚落宮

**情形二**：先問父親，再問母親
- 先以年干庚為父親用神（天盤庚落宮）
- 再以庚嘅合干乙為母親用神（天盤乙落宮）

**情形三**：同時分別問父母
- 比較年干(庚)同日干(甲)嘅陰陽屬性
- 庚(陽金)同甲(陽木)同屬陽 → 陰陽相同
- 年干庚 = 代表**母親**嘅用神
- 合干乙 = 代表**父親**嘅用神

> **關鍵提醒**：問測順序唔同，用神完全唔同！千萬唔好弄錯。

### 5. 方法三：主客關係
- **先動為客（天盤干），後動為主（地盤干）**
- 先問測嘅人/事 → 分析對應**天盤干**落宮
- 後問測嘅人/事 → 分析對應**地盤干**落宮
- 例子：先問父親（天盤年干）→ 再問老闆（地盤年干）→ 再問老闆娘（地盤年干合干）

### 6. 方法四：年命
- 年命 = 出生年份尾數對應嘅天干

| 年份尾數 | 天干 |
|----------|------|
| 4 | 甲 |
| 5 | 乙 |
| 6 | 丙 |
| 7 | 丁 |
| 8 | 戊 |
| 9 | 己 |
| 0 | 庚 |
| 1 | 辛 |
| 2 | 壬 |
| 3 | 癸 |

- 求測人一開始講咗出生年份 → **必須用年命做用神**
- 影響重大嘅事 → 最好問清楚年命再分析
- 可以解決四柱天干代表人物過於重疊嘅問題

### 7. 方法五：九宮八卦
- 唔清楚年份，只知大概年齡段時使用

| 宮位 | 代表人物 |
|------|---------|
| 乾(父) | 父親、男性長輩、年老男士 |
| 坤(母) | 母親、女性長輩、年老女士 |
| 巽(長女) | 大女兒、過中年女士 |
| 離(中女) | 二女兒、正直中年女士 |
| 兌(少女) | 小女兒、青春少女 |
| 震(長男) | 大兒子、過中年男士 |
| 坎(中男) | 二兒子、正直中年男士 |
| 艮(少男) | 小兒子、花樣少男 |

### 8. 方法六：方位
- 求測人坐嘅方位 / 事件發生嘅方位 = 用神宮
- 求測人坐離位 → 分析離宮
- 事件發生喺北方 → 分析坎宮
- 亦可配合「來人不用問」使用

### 9. 方法七：六親關係
- 以當事人年命為基礎，用五行相生相剋推算親屬用神
- 例子：年命丁(火) → 乙木(同性陰)生丁火 = 母親，甲木(異性陽)生丁火 = 父親
- 規則：生我者為父母（同陰陽=母，異陰陽=父）
- 比和者為平輩，我生者為子女

### 10. 方法八：專門用神

#### 婚姻專門用神
| 符號 | 代表 |
|------|------|
| 乙 | 女方 |
| 庚 | 男方 |
| 丙 | 女方情人 |
| 丁 | 男方情人 |
| 六合 | 婚姻本身 |

#### 官司專門用神
| 符號 | 代表 |
|------|------|
| 值符 | 原告 |
| 天乙 | 被告 |
| 六合 | 證據 |
| 開門 | 法官 |
| 丁 | 傳票 |
| 驚門 | 律師 |

> **原則**：有專門用神嘅事物，必須以專門用神為主。

### 11. 方法九：報數和編號
- 適用於多選項比較場景
- 求測人對各選項隨機編號
- 編號對應宮位 = 各選項用神宮
- 適用於投資選擇（EP09）、追求者比較等

### 12. 綜合運用原則
- 可以只用一種，亦可以同時用幾種
- **多角度分析 → 結果更加立體準確**
- 先確定主要用神，再用其他方法交叉驗證
