## 二、官司輸贏判斷三步法

1. **值符 vs 天乙**：值符宮剋天乙宮 → 原告贏；反之被告贏
2. **日干 vs 時干**：交叉驗證（日干=求測人，時干=所問之事）
3. **開門取向**：開門宮生值符宮 → 法院傾向原告

## 三、新凶格

| 格局 | 條件 | 含義 | 組合數 |
