# EP18: 刑事訴訟預測 + 入墓格局

## 本集新知識點

### 一、刑事訴訟用神體系
| 角色 | 用神 | 備註 |
|------|------|------|
| 疑犯 | 天干辛 | 辛=犯錯/錯誤的象意 |
| 疑犯(輔助) | 日干/年干/月干/時干 | 親自求測用日干，親朋代測按六親選 |
| 警察部門 | 傷門、白虎、天干庚 | 三個符號都代表警察 |
| 檢控部門 | 杜門 | 香港的律政司 |
| 法院/法庭 | 開門 | | 
| 監獄 | 辛=天獄、壬=地牢、癸=天網 | 現代含義 |
| 判刑 | 天干庚 | 雙重角色：警察+判刑 |

### 二、刑事訴訟階段判斷
- **拘捕**：辛臨白虎/庚/傷門/螣蛇 → 已被警方拘捕
- **檢控**：辛臨杜門 → 已移交檢控部門
- **審理**：開門宮 vs 辛宮的生剋關係

### 三、定罪判斷7條規則
1. 開門宮**生**辛宮 → 無罪
2. 開門宮與辛宮**比和** → 定罪但輕判/緩刑
3. 開門宮**衝/剋**辛宮 → 一定定罪，重判
4. **庚+辛**同宮 → 一定定罪，很重
5. **辛+辛/壬/癸** → 定罪+監禁
6. **庚宮剋辛宮** → 定罪
7. **辛落巽四宮** → 傾向定罪（巽=執法部門）

### 四、伏吟/反吟對刑事訴訟
- 伏吟 → 審理拖很久（持久戰）
- 反吟 → 審理快但要準備上訴

### 五、天干入墓
| 宮位 | 入墓天干 |
|------|----------|
| 坤二宮 | 甲、癸 |
| 乾六宮 | 乙、丙、戊 |
| 艮八宮 | 丁、己、庚 |
| 巽四宮 | 辛、壬 |

**特殊規則**：乙在坤二宮也屬入墓（代替甲）

### 六、八門入墓
| 宮位 | 入墓門 | 五行規則 |
|------|--------|----------|
| 巽四宮 | 生門、死門、休門 | 土水入墓於巽 |
| 坤二宮 | 傷門、杜門 | 木入墓於坤 |
| 乾六宮 | 景門 | 火入墓於乾 |
| 艮八宮 | 開門、驚門 | 金入墓於艮 |

### 七、出墓與衝墓
- 出墓：時間到入墓地支（如丁入墓於丑 → 丑年/月/日/時）
- 衝墓：時間到對衝地支（丑未衝 → 未年/月/日/時）
