# EP29: 佈局催財 — 先天命數vs後天命數 + 奇門催財方法

**頻道**: 天心堂 坤正師傅
**主題**: 奇門遁甲佈局催財的理論與實踐
**量化日期**: 2026-08-12

## 本集概述

本集首次系統性講解**奇門遁甲佈局催財**。前半探討「命裡無財還能不能催」這個根本問題（先天命數 vs 後天命數），後半講奇門佈局催財的具體方法、流程和優勢。呢集標誌住奇門項目從**純預測**延伸到**佈局調理**。

## 核心知識點

### 1. 先天命數 vs 後天命數

| 維度 | 先天命數 | 後天命數 |
|------|----------|----------|
| 來源 | 生辰八字推算 | 自身行為積累的福德 |
| 性質 | 與生俱來的人生框架 | 逐漸形成，可改變 |
| 範圍 | 固定 | 隨行為變化 |
| 作用 | 初始框架 | **最終決定作用** |

**核心論點**：
- 做好事、幫助人 → 積累福德 → 影響先天命數 → 形成後天命數
- 後天命數 > 先天命數（最終決定作用）
- 證據：生辰八字相同的人，人生完全不同
- **奇門佈局針對的是後天命數** → 就算命裡無財也有效

### 2. 坊間催財 vs 奇門催財

| 維度 | 坊間方法 | 奇門佈局催財 |
|------|----------|--------------|
| 依據 | 流年財星飛到嘅宮位 | 當時起的奇門盤局 |
| 適用對象 | 所有人（籠統） | 當事人一人（針對性） |
| 使用的力量 | 單一方位 | 九星+九宮+八門+八神 |
| 效果 | 比較低 | 普遍非常好 |
| 操作難度 | 簡單（普通人可做） | 需要師傅（否則反效果） |

### 3. 奇門佈局催財的四大力量

| 力量 | 對應 | 作用 |
|------|------|------|
| 天時 | 九星 | 天上嘅力量 |
| 地利 | 九宮八卦 | 地上嘅力量 |
| 人和 | 八門 | 人事嘅力量 |
| 神助 | 八神 | 神秘嘅力量 |

> 全方位同時利用四種力量 → 佔盡天時地利人和神助

### 4. 佈局地點選擇

| 優先級 | 地點 | 說明 |
|--------|------|------|
| 最佳 | 居所 + 工作地方 | 兩個一起佈局效果最好 |
| 次佳 | 居所 or 工作地方 | 選其一 |
| 多處居所 | 住得最多的那個 | |

原則：選當事人**經常停留或停留時間最多**的地方

### 5. 佈局流程

```
起奇門遁甲盤局
    ↓
分析當事人財政狀況
    ↓
找出影響財運的關鍵
    ↓
確定需要佈局調整的方位
    ↓
到現場量度方位（或遙距）
    ↓
制定具體佈局方案
    ↓
執行佈局
```

### 6. 遙距佈局
- 條件：當事人能提供**準確方位**和**平面圖**
- 效果：跟現場佈局**基本沒有分別**

### 7. 催財風水物
- 貔貅、三足金蟾、聚寶盆、水晶球、財神、風水輪等
- 嘅使用全由**盤局決定**（用哪種、如何用、在哪用）
- 無固定套路

### 8. 流年財星
- 2022年流年財星飛到**東北方**
- 坊間方法：在家裡東北方擺放催財風水物
