# EP19: 考試升學預測 + 值符與值使

## 本集新知識點

### 一、考試升學四用神
| 用神 | 代表 | 備註 |
|------|------|------|
| 日干 | 考生（親自求測） | 求測人自己 |
| 時干 | 考生（父母代測） | 父母為兒女求測時用時干 |
| 六親干 | 考生（其他代測） | 按六親關係選年干/月干/時干 |
| 年干 | 錄取學校 | 太歲=國家最高領導=最終錄取的那間學校 |
| 天輔星 | 繼續升學機會 | 有沒有書讀 |
| 景門 | 試卷/試題 | 考試內容 |

### 二、升學結果判斷方法
1. **景門宮 vs 考生宮**：景門生考生 → 答題好
2. **年干宮 vs 考生宮**：年干生考生 → 學校錄取
3. **天輔星宮 vs 考生宮**：天輔生考生 → 有升學機會
4. **綜合判斷**：三用神都生考生=大吉；都剋=凶；混合需權衡

### 三、DSE案例
- 時干己落乾六宮（考生）
- 景門落坤二宮(土) → **生**乾六宮(金) = 試卷生考生
- 年干戊落坤二宮 → **生**乾六宮 = 學校錄取考生
- 天輔星同落坤二宮 → 三重印證
- 結果：考上本地大學電子工程
