# EP31: 來人不用問 — 從盤局讀出求測人嘅問題

**頻道**: 天心堂 坤正師傅
**主題**: 來人不用問技巧 + 完整案例（女士外遇離婚）
**量化日期**: 2026-08-13

## 本集概述

本集介紹奇門遁甲最神奇嘅技巧之一：**來人不用問** — 求測人未開口，師傅已經從盤局讀出佢想問咩。前半講解呢個技巧嘅原理同步驟，後半用一個完整案例（女士有外遇、想離婚但猶豫不決）展示整套分析流程。

## 核心知識點

### 1. 來人不用問嘅定義
- **學會奇門遁，來人不用問** — 古代對奇門遁甲預測能力嘅最高讚譽
- 係一種**真實存在**嘅技術，唔係賣花讚花香
- 前提：求測人必須真係有事要問、誠心誠意（EP16 起局原則）
- 如果只係為咗驗證而隨便問，起出嚟嘅局唔會準

### 2. 來人不用問嘅分析步驟

```
第一步：分析日干（求測人自身狀態）
  ↓
第二步：分析時干（求測之事）
  ↓
第三步：觀察日干與時干嘅關聯（是否同宮、生剋關係）
  ↓
第四步：根據線索鎖定問題類型（如丙出現→感情）
  ↓
第五步：查看相關宮位確認（如感情→乙庚、六合宮）
  ↓
第六步：分析值使門（求測人心態）
  ↓
第七步：綜合判斷，講出求測人嘅問題
```

### 3. 關鍵觸發信號

| 日干宮出現 | 可能問題方向 |
|-----------|-------------|
| 丙 | 男女關係、感情問題 |
| 庚 | 官司、競爭對手、丈夫 |
| 辛 | 罪犯、官非 |
| 天芮星 | 疾病、健康問題 |
| 開門 | 工作事業、開業 |
| 生門 | 財運、利潤 |
| 戊 | 資金、錢財問題 |

> **核心邏輯**：日干宮嘅信息揭示求測人嘅狀態，而日干宮出現嘅特殊符號（如丙）自動指向特定問題類型。

### 4. 完整案例：女士外遇離婚

#### 案例背景
- 一位女士落座後一直唔講自己想問咩
- 不斷環顧四周，講緊毫不相關嘅嘢
- 師傅用當時時間起局，直接判斷佢想問咩

#### 第一步：日干壬落乾六宮

| 用神 | 象意 | 判斷 |
|------|------|------|
| 壬（日干=求測人） | 水 | 女士本人 |
| 值符 | 貴人、高地位 | 管理層或老闆 |
| 天英星 | 火、急躁 | 性格火爆 |
| 死門 | 閉塞、不暢 | 心情極差 |
| 壬+丙 | 壬水克丙火 | **丙=感情關係線索** |

**初步判斷**：有一定地位嘅女士，性格急躁，目前面臨口舌爭鬥，情緒低落。丙嘅出現暗示感情問題。

#### 第二步：時干丙落震三宮

| 用神 | 象意 | 判斷 |
|------|------|------|
| 丙（時干=事件） | 火、感情 | 事件涉及男女關係 |
| 玄武 | 暗昧、隱瞞 | **桃色成分、偷偷摸摸** |
| 休門 | 休息、隱藏 | 悄悄進行 |
| 天心星 | | |
| 丙+己 | | 源於自我慾念 |
| 空亡 | | 早已發生（生米煮成熟飯） |

**判斷**：事件涉及桃色成分，源於慾念，早已發生，正在暗中進行。

#### 第三步：日干時干關聯
- 日干壬下臨丙 → 丙同時係時干
- **日時同宮**：事情已經發生而且正在進行當中
- 時干宮(震/木) vs 日干宮(乾/金)：金剋木 → 日干剋時干
- 但根據第三者判斷原則（EP03），此處時干丙作為第三者似乎唔完全成立
- 需要進一步確認

#### 第四步：六合宮（婚姻宮）

| 用神 | 象意 | 判斷 |
|------|------|------|
| 六合落離九宮 | 離=火 | 婚姻宮 |
| 傷門 | 傷害 | 互相傷害 |
| 天任星 | 土、固執 | 雙方固執任性 |
| 癸+壬 | | 婚姻關係極差 |

**判斷**：婚姻關係非常差，雙方固執，經常衝突，互相傷害。

#### 第五步：交叉驗證
- 時干丙宮(震/木) **生** 六合宮(離/火) → 木生火 → 事件(外遇)直接影響婚姻
- 六合宮有地盤壬 = 日干 → 求測人自己係婚姻問題嘅核心

#### 第六步：乙庚同落坎一宮

| 用神 | 象意 | 判斷 |
|------|------|------|
| 乙（妻）+ 庚（夫） | 同宮 | 夫妻在一起 |
| 九天 | 高調 | 吵鬧公開 |
| 驚門 | 驚恐、爭吵 | **只有吵吵鬧鬧** |
| 天芮星+天禽星 | 病星 | 關係有病態問題 |
| 乙+辛、庚+辛 | 辛=錯誤/罪 | 雙方都有錯 |

- 乙庚宮(坎/水) **衝剋** 六合宮(離/火) → 水剋火 → 夫妻對婚姻極度不滿
- 乙宮(坎/水) **生** 丙宮(震/木) → 水生木 → **妻子(乙)主動生旺第三者(丙)** → 外遇確認！
- 乙宮臨九天 → 求測人心已不在婚姻，想遠走高飛

#### 第七步：值使景門落兌七宮

| 用神 | 象意 | 判斷 |
|------|------|------|
| 景門（值使） | 火克金 | **門迫** |
| 騰蛇 | 糾纏、矛盾 | 自我矛盾、糾結 |
| 天輔星 | | |
| 戊+丁 | | 是非對錯之間掙扎 |

**判斷**：求測人內心極度矛盾，糾結於是非對錯，無法作出決定。

#### 最終結論

> 求測人由於婚姻關係非常不好，加上有了外遇，現在打算提出離婚。但離婚嘅想法搖擺不定，一時間無法下定決心，所以過來問測於奇門遁甲，希望幫自己做決定。

女士聽到之後連連點頭，話實際情況完全一樣。

### 5. 來人不用問嘅使用限制（重要）

**不建議經常使用**，原因：

1. **準確度考量**：求測人提供背景資料可以大幅提升預測準確度
2. **用神多義性**：同一個用神喺唔同情境下有完全唔同嘅解釋（例如丙可以係感情，也可以係文章、文明）
3. **目的優先**：求測人最大目的係得到準確結果，而唔係睇師傅表演「來人不用問」
4. **正確定位**：來人不用問只係**輔助工具**，用嚟提前知道求測人嘅想法，唔可以作為斷局嘅主要依據

> 師傅原話：「大家平時運用來人不用問的技巧，只是可以用作幫我們提前知道一下求測人的想法和心意，千萬不要完全靠它作為斷局的主要依據。」
