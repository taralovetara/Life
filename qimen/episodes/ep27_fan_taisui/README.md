## 知識點

### 1. 太歲基礎概念
- 太歲 = 太歲神/太歲星君，道教每年當值神靈
- 掌管人世間全年吉凶禍福
- 共 **60 位**太歲神，對應 60 甲子
- 每位太歲神有名有姓，生前多為賢德之人
- 最早來自商朝，最後一位來自明朝
- 大多數來自宋明兩代（道教盛行的朝代）
- 2022 壬寅年太歲神 = **賀諤**

### 2. 五種傳統犯太歲

#### 2.1 值太歲（本命年）
- 生肖 = 值年太歲的地支生肖
- 與太歲神「平起平坐」，分享權力
- 老話：**太歲當頭坐，無福恐有禍**

|------|------|

| 寅巳申刑 | 虎、蛇、猴 |

| 辰自刑 | 龍 |

| 亥自刑 | 豬 |

刑太歲 → 身體傷病、是非官司

### 3. 奇門遁甲犯太歲（本集核心）

#### 3.1 奇門太歲定義
- 奇門以**天干為主、地支為輔**
- 太歲主要指**年干**
- 年干權力覆蓋全年 = 盤面中權力最大
- 也要兼顧年支

#### 3.2 兩種奇門犯太歲

| 類型 | 條件 | 類比傳統 |
|------|------|----------|
| 用神剋年干 | 用神落宮五行 **剋** 年干落宮五行 | 犯太歲（造反） |
| 用神衝年干 | 用神落宮與年干落宮 **對衝**（宮位相衝） | 衝太歲 |

#### 3.3 關鍵規則
- **年干剋用神 ≠ 犯太歲**（上級管下級正常）
- **只有用神剋年干才算**（以下犯上 = 造反）
- 犯太歲結果：太歲強勢回應，用神全年不順，謀事難成
- 犯太歲建議：暫勿實施大行動或大計劃

#### 3.4 查其他年份太歲
- 盤面年干只代表起局年份
- 查其他年份：找出該年天干在天盤嘅落宮，與用神比較
- 例如查明年癸卯年：找天盤癸落宮 vs 日干宮
- 可進一步結合年支宮做綜合判斷

### 4. 奇門 vs 傳統犯太歲比較

| 維度 | 奇門遁甲 | 傳統生肖 |
|------|----------|----------|
| 對象 | 個人（唯一性） | 整個生肖（~1/12人口） |
| 精準度 | 非常高 | 粗糙 |
| 針對性 | 針對問測之事 | 籠統 |
| 層次 | 高 | 低 |
