## 核心知識點

### 1. 為什麼需要寄宮
- 八門八神各8個，分佈八卦宮後中五宮無門無神
- 缺門神=信息不完整=影響準確度
- 解決：星干寄放其他宮位，借用門神

### 2. 四種寄宮方法
| 方法 | 寄宮位置 | 原理 |
|------|----------|------|
| 一 | 固定坤二宮 | 孝道+五行閉環 |
| 二 | 陽遁艮/陰遁坤 | 易經陰陽生剋+先後天八卦 |
| 三 | 四維宮(按季節) | 四季轉換+皇帝巡視 |
| 四 | 八卦宮(按節氣) | 八節氣+皇帝巡視 |

### 3. 五行閉環原理
- 南火→西南土(坤)→西金→北水→東木→南火 = 完美圓形

> 四種方法全部正確，準確度無分別。
