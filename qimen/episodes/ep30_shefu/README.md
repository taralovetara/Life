# EP30: 射覆 — 奇門遁甲古代猜謎遊戲 + 心臟藥案例

**頻道**: 天心堂 坤正師傅
**主題**: 射覆方法論 + 完整射覆案例（心臟藥）
**量化日期**: 2026-08-12

## 本集概述

本集介紹**射覆**— 一種用術數猜度被蓋住物品的古代遊戲。前半講射覆的歷史和方法演變，後半用一個完整案例（朋友褲兜裡的心臟藥）展示師傅的綜合射覆方法。呢集包含大量**象意對應**知識，係訓練斷局能力嘅好材料。

## 核心知識點

### 1. 射覆定義與歷史
- **射** = 猜度，**覆** = 蓋住
- 唐朝考核**天文郎**（掌管天文嘅官員）嘅考試科目
- 朱元璋考劉伯溫 → **燒餅歌**典故
- 可用嘅術數：六爻、梅花易數、大六壬、奇門遁甲等
- 奇門遁甲歷來係射覆嘅**佼佼者**（用神多、描述精細）

### 2. 三種射覆方法比較

| 方法 | 用神 | 時代 | 評價 |
------|------|------|------|
| 古籍法 | **值使門**為主 | 古代 | 不夠全面 |
| 現代法 | **時干**為主 | 現代 | 不夠全面 |
| **師傅法（本集）** | **天盤時干 + 地盤時干 + 值使門** | 現代改良 | **最全面** |

> 師傅結論：三個用神必須**同時分析**

### 3. 射覆判斷維度

| 維度 | 說明 |
------|------|
| 生死 | 活物定死物 |
| 形狀 | 圓形、方形、長條等 |
| 大小 | 體積 |
| 顏色 | 對應五行顏色 |
| 軟硬 | 對應五行性質 |
| 虛實 | 實心/空心/容器 |
| 數目 | 數量 |

### 4. 心臟藥射覆案例

#### 盤面信息

**天盤時干壬落艮八宮**：
| 用神 | 象意 |
|------|------|
| 壬（天干） | 水、黑色 |
| 艮八宮（空亡） | 土的性質、東西已缺失 |
| 九地 | 土的性質 |
| 開門 | 可打開的 |
| 庚（天干） | 堅硬 |
| 天心星 | 醫療、醫藥 |
| 壬處病地 | 與天心星對應（有病） |

**對宮坤二宮（因艮宮空亡而參考）**：
| 用神 | 象意 |
|------|------|
| 杜門 | 閉合的、不對外公開 |
| 天輔星 | 補充、輔助 |
| 太陰 | 私底下使用、不公開 |
| 乙（天干） | 醫療、醫藥 |
| 癸（天干） | 液體、透明物體 |
| 丁（天干） | 尖銳、體積小、**心臟** |
| 坤宮 | 容器、土的性質 |

**地盤時干壬落乾六宮**：
| 用神 | 象意 |
|------|------|
| 值符、值使 | **經常使用**的東西 |
| 天芮星 | 醫療、醫藥（病星） |
| 乙（天干） | 醫療、醫藥 |
| 死門（值使門） | 土的性質、**生死**相關 |
| 癸（天干） | 液體、透明物體 |
| 乾宮 | **心臟**的象意 |

#### 綜合判斷
| 特徵 | 來源 | 判斷 |
|------|------|------|
| 救命藥物 | 天心+天芮+死門（生死） | 藥物 |
| 經常服用 | 值符值使同宮 | 長期用藥 |
| 玻璃/陶瓷瓶 | 庚(堅硬)+坤(容器)+乾(金) | 白/黃色瓶子 |
| 可開合 | 開門+杜門 | 蓋子隨意開合 |
| 黑色細小顆粒 | 壬(水/黑)+丁(小) | 藥丸形態 |
| 已吃完大半 | 空亡 | 剩餘很少 |
| 心臟藥 | 丁(心臟)+乾宮(心臟) | **心臟病藥物** |
| 昂貴 | 值符值使+天心星 | 貴價藥物 |

#### 實際結果
- 白色瓶子，裝著黑色細小顆粒藥丸
- 基本吃完，只剩一點點
- 朋友心臟有問題，需經常服用心臟藥
- 藥非常貴
