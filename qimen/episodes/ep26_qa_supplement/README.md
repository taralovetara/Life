## 12 個問題與知識點

### Q1: 起局 App 選擇
- 三種起局模式：**拆補法**、置閏法、茅山法
- 本頻道統一採用 **拆補法**
- 選 App 唯一標準：支援拆補法模式即可

### Q2: 23 點起局算當天定第二天？
- **現代記時**：24 小時制，23:00 仍屬當天
- **干支記時**：12 時辰制，**23:00 已進入子時 = 第二天**
- 奇門遁甲用干支記時 → **23:00 起局算第二天**

### Q3: 內盤與外盤嘅定義

| 局類 | 內盤（1-4宮） | 外盤（6-9宮） |
|------|---------------|---------------|
| 陽遁 | 坎(1)、艮(8)、震(3)、巽(4) | 離(9)、坤(2)、兌(7)、乾(6) |
| 陰遁 | 離(9)、坤(2)、兌(7)、乾(6) | 坎(1)、艮(8)、震(3)、巽(4) |

**規律**：陽遁內盤 = 陰遁外盤，互相顛倒。中五宮唔計入內外盤。

### Q4: 內外盤嘅預測意義

| 用神落位 | 速度 | 時間 | 方位 |
|----------|------|------|------|
| 內盤 | 快 | 短 | 近 |
| 外盤 | 慢 | 長 | 遠 |

### Q5: 中五宮寄宮方法

| 寄宮流派 | 方法 |
|----------|------|
| 陰陽分寄 | 陽遁寄艮八、陰遁寄坤二 |
| 季節分寄 | 春寄艮八、夏寄巽四、秋寄坤二、冬寄乾六 |
| **本頻道採用** | **統一寄坤二宮，不論陰陽遁、不論季節** |

> 轉盤奇門嘅寄宮一直有爭議，本頻道選擇最簡單最常用嘅方法。

### Q6: 天禽星 vs 天芮星同宮判斷
- 天禽寄天芮，永遠同宮
- **主次原則**：睇用神天干**原本所臨嘅天星**
  - 用神干原本喺中五 → 以**天禽**為主
  - 用神干原本喺坤二 → 以**天芮**為主
- **輔助參考**：另一顆星也要參考，因為同宮會共同作用
- 有寄宮嘅宮位信息量更大

### Q7: 多次起局揀好盤？
- **絕對唔可以**
- 必須按「求測人起念的時間」或「外應出現的時間」起局
- 為搵好盤而多次起局 = 違背起局原則 → 盤局唔正確 → 結果不準

### Q8: 不同時區點起局？
- **以起局者所在時區為準**
- 身處香港為英國朋友測 → 用香港時間
- 身處英國為英國朋友測 → 用英國時間
- 核心原則：**起局者當地時間**

### Q9: 地支既相合又相刑？
- **相刑力量 >> 相合力量**
- 相合只能抵消相刑的「很輕微」部分
- 整體情況無大改變 → **以相刑來判斷**

### Q10: 乙庚好但日時壞？
- **乙庚 = 長期大趨勢**（婚姻長久關係）
- **日時 = 短期現狀**（目前一段時間）
- 乙庚為主，日時為輔
- 比喻：乙庚 = 永恆，日時 = 短暫

### Q11: 只分析用神夠唔夠？
- **絕對唔夠**
- 奇門盤 = 四維立體模型（天、地、人、神）
- 用神受九星、八門、八神、九宮八卦共同影響
- **必須全盤考慮、綜合分析**，唔可以將用神獨立

### Q12: 能否預測企業/公司？
- 奇門以「問事時間點」起局，唔涉及生辰八字
- 可以預測企業：找出有問題的部門、提供改善建議
- 可以識別：邊個員工可信、邊個係「間諜」
- 師傅認為：奇門分析企業 > 聘請顧問公司
