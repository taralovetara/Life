# EP38: 仙家怪病 — 用螣蛇落宮鎖定胡黃白柳灰五位仙家

**頻道**: 天心堂 坤正師傅
**主題**: 陰性物質侵入怪病 + 五位仙家介紹 + 螣蛇落宮五行對應診斷法
**量化日期**: 2026-08-13

## 本集概述

本集介紹一個特殊應用：當有人無故得咗醫院查唔到原因嘅怪病，行為神情言語都變咗另一個人，從術數角度可能係陰性物質侵入。最容易造成影響嘅係**胡、黃、白、柳、灰**五位仙家。用奇門遁甲嘅**螣蛇落宮五行**對應，可以確定係邊位仙家造成嘅影響。

## 核心知識點

### 1. 陰性物質侵入嘅特徵
- 無故得怪病，醫院查唔到原因
- 行為、神情、言語同平常完全唔同
- 好似變咗另一個人
- 對身心同時打擊

| 胡仙 | 狐狸 | 胡三爺 | 火 | 紅色+狐通火 | 法力高、恩怨分明、可幻化俊男美女 |
| 黃仙 | 黃鼠狼 | 黃二爺 | 土 | 黃色 | 附身能力極強、操控意識行為、特別記仇 |

### 3. 螣蛇落宮診斷法

- 螣蛇代表陰性、詭異、暗昧嘅物質
- 被陰性物質附體/侵入 → 螣蛇落宮會反映出嚟
- **診斷方法：螣蛇落宮嘅五行屬性 → 對應仙家**

| 螣蛇落宮 | 宮位五行 | 對應仙家 | 動物 |
|------------|----------|----------|------|
| 離九宮 | 火 | 胡仙 | 狐狸 |
| 坤二宮 / 艮八宮 | 土 | 黃仙 | 黃鼠狼 |
| 乾六宮 / 兌七宮 | 金 | 白仙 | 刺猬 |
| 震三宮 / 巽四宮 | 木 | 柳仙 | 蛇 |
| 坎一宮 | 水 | 灰仙 | 老鼠 |

> **注意**：影片中坎宮水對應蛇仙，但柳仙=蛇=木、灰仙=鼠=水，正確對應應為坎宮→灰仙。此處應為師傅口誤。

### 4. 五位仙家詳細背景

#### 胡仙（狐狸）
- 吸收天地靈氣、月亮精華修煉
- 每 500 年尾巴裂開一條，九尾狐=最高境界
- 最有名：化身妲己嘅九尾狐
- 法力高、報復傷害性高，但恩怨分明，唔會無故傷人

#### 黃仙（黃鼠狼）
- 附身能力極強，操控人類意識行為
- 被附身者會做出類似黃鼠狼嘅行為（嚎叫、跳躍）
- 時間長會逐漸衰弱甚至死亡
- **特別記仇**：出動全家老小宗族親朋一起報復，不達目的絕不罷休

#### 白仙（白色刺猬）
- 五位大仙中**心性定力最強**
- **唔係亦正亦邪**，對人類非常友善
- 精通巫術，擅長治療疑難雜症
- 得罪白仙 → 福祿流失、身體衰弱、容易短命

#### 柳仙（蛇）
- 伏羲女媧=人首蛇身，最早受崇拜嘅蛇仙
- 蛇百年成蟒、千年成蛟、萬年成龍
- 靈氣高、行動詭秘靈敏
- 千里攝魂法術，法力唔低於狐仙
- 民間禁忌：不打入屋蛇

#### 灰仙（老鼠）
- 晝伏夜出、行蹤難捉摸
- 傳說：開暗道運走貪官扣留嘅賑災糧食派發災民
- 被視為**倉神**，甚至成為**財神**

### 5. 處理原則
- 五位仙家大多以行善為主
- 刻意冒犯先會招致懲罰
- 解鈴還需繫鈴人：確定病因 → 針對性處理
- 螣蛇落宮確定仙家 → 後續處理方法（本集不詳述）
