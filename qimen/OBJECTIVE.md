# 研究目標

## 核心目的

**用騰訊（0700.HK）股價做 back test，認證奇門遁甲有冇預測能力。**

所有研究、優化、補足，都必須服務於呢個目的。如果一項改進不能提升 back test 的可靠性或解讀力，則優先級降低。

## 方法論原則

1. **二元決策回測** — 奇門本質是運籌學（做/唔做），回測設計為分類問題
   - 正確做法：奇門分數 → 決定「做/唔做」 → 對比實際漲跌
   - 錯誤做法：奇門分數 → 預測漲跌幅（連續變量）

2. **先完善引擎，再做回測** — 確保引擎邏輯正確，否則 back test 結果無意義

3. **每項優化必須可量化驗證** — 改完引擎之後，要能夠用 back test 對比改前改後

## Back Test 框架（待重建）

```
問事時間（每交易日上午9:30巳時）
  ↓
奇門起局 → 各宮評分
  ↓
離9宮（科技股=騰訊）總分 → 二元決策
  ↓
對比：決策日 + N日 的騰訊股價變化
  ↓
統計：勝率、p-value、AUC
```

但**二元決策角度**尚未系統性測試 — 這是下一步方向。
