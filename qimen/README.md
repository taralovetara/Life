# 奇門遁甲 Qi Men Dun Jia

時空決策量化系統，用於揀選投資入出市時機。

## 框架邏輯

```
輸入: datetime
  ↓
日干支 → 時辰干支 → 旬首 → 值符/值使
  ↓
節氣+元 → 局數 → 地盤 (~5日一變)
  ↓
天盤(星+干) + 人盤(門) + 神盤(神) — 每時辰一變
  ↓
格局偵測 + 五行生剋 + 評分 → 決策輸出
```

## 檔案說明

| 檔案 | 用途 |
|------|------|
| `engine.py` | 完整起局引擎（地/天/人/神盤飛布 + 格局 + 評分） |

## 評分公式

```
宮位總分 = 星分 + 門分 + 神分 + 干支生剋 + 格局加減分
```

## 同紫微斗數嘅分工

| 維度 | 紫微斗數 | 奇門遁甲 |
|------|---------|---------|
| 用途 | 年度大方向預測 | 即時時機揀選 |
| 粒度 | 年 | 時辰（2小時） |
| 基底 | 本命盤（固定） | 地盤（~5日） |
| 複雜度 | 解讀複雜 | 計算複雜 |

## 注意事項

- 節氣日期為 2026 年近似值，精確起局需配合萬年曆
- 日干支公式已用 2000-01-01=戊午日校準
